# 오늘 뭐 먹지? 메뉴 룰렛

메뉴 후보를 직접 고르거나 무작위로 채우고, 룰렛으로 오늘의 한 끼를 정하는 반응형 웹앱입니다. 인원별 함께 먹기 추천과 날짜·계절별 오늘의 메뉴도 확인할 수 있습니다.

## 링크

- **GitHub 저장소:** [lsylsy01361130-cell/menu](https://github.com/lsylsy01361130-cell/menu)
- **GitHub Pages:** [https://lsylsy01361130-cell.github.io/menu/](https://lsylsy01361130-cell.github.io/menu/)

GitHub Pages는 `main` 브랜치에 반영되는 GitHub Actions 워크플로로 배포됩니다. 최초 배포 전 저장소 설정에서 Pages의 배포 소스를 **GitHub Actions**로 지정해야 하며, 배포 완료 후 위 주소에서 앱을 사용할 수 있습니다.

## 앱 소개

- 파스텔톤 UI와 흐릿한 음식 장식 배경의 모바일·데스크톱 반응형 메뉴 룰렛
- 기본 후보 12개와 중복 없는 랜덤 메뉴 10개 설정
- 한식·중식·일식·양식·분식·아시아·계절/보양식·고기/모임 카테고리 탐색
- 2~10인 규모에 맞는 함께 먹기 좋은 메뉴 10개 추천
- 기념일·복날 등 등록된 날짜에는 어울리는 메뉴와 한 줄 설명을 제공하고, 그 외에는 계절 메뉴를 추천
- 메뉴별 1인분 기준 예상 칼로리와 단백질 표시. 정보가 없는 직접 입력 메뉴는 미등록으로 안내
- 브라우저 `localStorage`를 통한 메뉴 후보 저장

## 사용법

1. 웹앱을 열어 현재 메뉴 후보와 오늘의 추천 카드를 확인합니다.
2. 메뉴 이름을 직접 입력하거나 **카테고리별 메뉴**의 메뉴를 눌러 후보에 추가합니다.
3. **전체 메뉴를 랜덤으로** 눌러 후보를 무작위 10개로 교체하거나, 인원수를 고르고 **같이 먹기 추천**을 누릅니다.
4. 오늘의 추천 메뉴는 **후보에 추가** 버튼으로 룰렛 후보에 넣을 수 있습니다.
5. 후보가 2개 이상일 때 **룰렛 돌리기**를 눌러 오늘의 메뉴를 선택합니다.
6. 후보 옆 삭제 버튼으로 개별 삭제하거나 **전체 비우기**로 초기화합니다.

후보는 이 브라우저에 저장됩니다. 직접 후보를 삭제하면 10개 미만으로 줄어들 수 있으며, 룰렛 실행에는 최소 2개가 필요합니다.

## 로컬 실행

`index.html`을 최신 브라우저에서 열면 됩니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## GitHub Pages 배포

`.github/workflows/pages.yml`이 `main` 브랜치 푸시 또는 수동 실행 시 정적 사이트를 배포합니다. 최초 배포 전 저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택하세요.

## 영양정보와 날짜 안내

영양정보는 메뉴별 1인분 기준의 대략적인 참고치이며 실제 조리법과 분량에 따라 달라집니다. 특별한 날 추천은 코드에 등록된 날짜를 기준으로 표시합니다. 복날 날짜는 해마다 달라지므로 다음 연도의 복날 날짜는 확인 후 갱신해야 합니다.
